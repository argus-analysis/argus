# ARGUS Protocol V5.0.0

**Release date:** 2026-08-21

ARGUS V5.0.0 is the current stable normative protocol.

This release contains the protocol in six languages: French, English, Spanish, German, Italian and Portuguese.

The French source is the normative source bundled with the stable ARGUS Skill wrapper.
