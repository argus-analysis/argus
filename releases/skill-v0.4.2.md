# ARGUS Skill 0.4.2

**Release date:** 2026-08-21  
**Target protocol:** ARGUS V5.0.0  
**Status:** stable

ARGUS Skill 0.4.2 is the stable execution wrapper for ARGUS Protocol V5.0.0.

The Skill does not replace the protocol. ARGUS V5.0.0 remains the normative reference.

## Tested hosts

Smoke-tested with:

- ChatGPT 5.6
- Claude Opus 5

Both hosts applied the substantive wrapper corrections. A known presentation-only limitation remains on ChatGPT 5.6 concerning the Markdown marker used for some bullet lists.
